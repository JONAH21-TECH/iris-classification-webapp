Dataset & Project Methodology

Documentation of the Machine Learning pipeline implemented for this assignment.

1️⃣

Dataset Specs

  • Origin: Scikit-Learn Built-in (Fisher, 1936)
  • Instances: 150 samples
  • Classes: 3 (Setosa, Versicolor, Virginica)
  • Distribution: 50 samples per class (100% balanced)
2️⃣

Preprocessing

  • Data Split: 80% Train (120), 20% Test (30)
  • Stratification: Class proportions preserved in split
  • Scaling: StandardScaler (Zero-mean, unit-variance)
  • Data Leakage Prevention: Scaler fitted on Train only
3️⃣

Algorithm Choice

  • Model: Random Forest Classifier
  • Estimators: 100 decision trees
  • Ensemble Method: Bagging with feature bootstrap
  • Reproducibility: Fixed random_state=42
